An offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5: a saved checklist with export and import, filters by kind, a spoiler setting, a roadmap to the platinum with the one possibly missable trophy flagged, and an own-words guide with named sources for every trophy.
## Run it
```sh
node serve.ts
```
